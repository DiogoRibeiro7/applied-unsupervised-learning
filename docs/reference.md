# API reference

`unsup_lab` is the tested package behind the notebooks. Everything below is generated from the docstrings in the source, so this page cannot drift from the code.

The modules divide into four groups: **making data** to model, **evaluating** structure without labels, **methods** for particular kinds of structure, and a **production layer** that carries a model out of the notebook.
