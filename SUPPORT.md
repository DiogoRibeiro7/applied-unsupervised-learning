# Support

Use GitHub issues for reproducible bugs, documentation fixes, and scoped feature
requests.

For modelling questions, include:

- The notebook or module involved.
- The command or cell that failed.
- Python version and operating system.
- A minimal example or the synthetic dataset generation parameters.
- The full error message when applicable.

This repository is not a support channel for private datasets or production
systems. Keep examples reproducible with public or synthetic data.
